# Security Policy

## Supported Versions

Security updates and critical patches are actively provided for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

---

## Reporting a Vulnerability

We take the security and physical safety of social robotics systems very seriously. If you discover a security vulnerability, credential leak, or physical safety issue (e.g. servo range runaway, unverified execution vulnerability):

1. **Do NOT open a public GitHub issue.**
2. Send an email with details and reproduction steps to the core maintainers:
   - **Email**: `gogordon@iu.edu`
   - **Subject**: `[SECURITY VULNERABILITY] Gigi Robot Platform`
3. Include the following details:
   - Type of issue (e.g., buffer overflow, authentication bypass, command injection, motor runaway)
   - Affected components and versions
   - Step-by-step instructions to reproduce
   - Potential impact on physical robot hardware or user safety

### Response Timeline
- We will acknowledge receipt of your vulnerability report within **48 hours**.
- We will provide a status update or fix within **7 business days**.
- Once patched, a security release will be published and credit will be given to the reporter (if desired).
